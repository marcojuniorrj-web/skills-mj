# SPEC › Usuários

1. Descubra o projeto (pasta `docs/<projeto>/`). Se não houver, pergunte o nome e crie.
2. Leia os arquivos de `docs/<projeto>/spec/` que já existirem — não repita o que já foi respondido.
3. Faça as perguntas abaixo **em blocos de 3 a 4**, usando a ferramenta de perguntas com opções
   quando houver respostas típicas. Se o usuário não souber, sugira o padrão sensato e marque "assumido".
4. Crie `docs/<projeto>/spec/usuarios.md` a partir de `docs/modelos/spec/usuarios.md`. Mostre um resumo e peça aprovação.
5. Diga qual é a próxima skill da SPEC.

## Perguntas
- Quem vai usar (corretor, gerente, cliente final, diretoria)? Quantas pessoas de cada?
- O que cada perfil quer resolver com o app?
- Em que momento e em que dispositivo cada um usa (celular na rua, computador no plantão)?
- O que cada perfil pode ver, criar, editar e apagar?
- Descreva o passo a passo típico de cada perfil.
- Precisa de login? Como a pessoa entra pela primeira vez?

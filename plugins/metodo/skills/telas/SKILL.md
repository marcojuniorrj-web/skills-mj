# SPEC › Telas

1. Descubra o projeto (pasta `docs/<projeto>/`). Se não houver, pergunte o nome e crie.
2. Leia os arquivos de `docs/<projeto>/spec/` que já existirem — não repita o que já foi respondido.
3. Faça as perguntas abaixo **em blocos de 3 a 4**, usando a ferramenta de perguntas com opções
   quando houver respostas típicas. Se o usuário não souber, sugira o padrão sensato e marque "assumido".
4. Crie `docs/<projeto>/spec/telas.md` a partir de `docs/modelos/spec/telas.md`. Mostre um resumo e peça aprovação.
5. Diga qual é a próxima skill da SPEC.

## Perguntas
- Qual é a primeira tela que a pessoa vê?
- Quais telas são necessárias para cada jornada?
- O que aparece em cada tela (campos, botões, listas, gráficos)?
- O que acontece quando não há dados, quando dá erro e quando dá certo?
- Será usado mais no celular ou no computador?
- Há identidade visual (logo, cores, fontes, tom de voz)? Algum app de referência?

# SPEC › Visão

1. Descubra o projeto (pasta `docs/<projeto>/`). Se não houver, pergunte o nome e crie.
2. Leia os arquivos de `docs/<projeto>/spec/` que já existirem — não repita o que já foi respondido.
3. Faça as perguntas abaixo **em blocos de 3 a 4**, usando a ferramenta de perguntas com opções
   quando houver respostas típicas. Se o usuário não souber, sugira o padrão sensato e marque "assumido".
4. Crie `docs/<projeto>/spec/visao.md` a partir de `docs/modelos/spec/visao.md`. Mostre um resumo e peça aprovação.
5. Diga qual é a próxima skill da SPEC.

## Perguntas
- Qual é o objetivo da aplicação?
- Que problema ela resolve? O que acontece hoje sem ela?
- Como saberemos que deu certo (tempo, conversão, vendas, leads)?
- Qual o mínimo que já geraria valor na primeira semana?
- O que fica para depois? O que definitivamente não faz parte?
- Prazo, orçamento, ferramentas obrigatórias? Uso interno ou público?
